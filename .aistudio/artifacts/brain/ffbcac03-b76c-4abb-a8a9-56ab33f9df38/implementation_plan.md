### 2. 数据模型与编辑器增强 (Data Model & Editor Enhancements)

- **个人信息 (`BasicsInfo`) 扩展字段**：
  - `directionTags`：岗位下方的技术方向副标题（如 `MCU 固件 / 实时系统 / 智能控制`），可在「个人基本信息」编辑器中直接修改。
  - `schoolTag`：右上角对齐展示的「院校」字段（默认自动同步第一段教育经历院校，也支持手动修改）。
  - `statusTag`：右上角对齐展示的「状态」字段（如 `电子信息工程 · 2027 届本科 · 随时到岗`）。
- **模块中英双语标题 (`SectionConfig`)**：
  - 为每个模块增加 `englishTitle` 属性（`EDUCATION`、`EXPERTISE`、`ACHIEVEMENT`、`ABOUT ME`、`PROJECT EXPERIENCE`、`INTERNSHIP EXPERIENCE`），支持在左侧编辑器中自定义修改中文与英文副标题。
- **模板选择器更新**：
  - 将这套 1:1 复刻版式设为默认首推模板 **「经典工程双栏风 (PDF 同款版式)」**，同时保留原有的现代极简、大厂单栏 ATS 等模板供随时切换对比。
