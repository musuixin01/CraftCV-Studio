## 一、项目最终目标

把 CraftCV-Studio 建成**本地优先、完整母版驱动的专业简历制作工作台**。适用于实习、应届、社招、资深岗位、转岗以及技术与非技术职业。

- **统一母版**：用户整理一次真实个人资料，包含教育、项目、工作/实习、技能、成绩、奖项证书、项目成果和证明文件；多个岗位版本复用，保留来源与确认状态。优先扩展现有内容库，而不是创建重复数据库。
- **岗位化生成**：输入目标职位或真实 JD，从完整母版选择最相关素材，说明选材理由；用户可查看、删选、修改并确认。生成的是新版本，不覆盖原稿。
- **专业润色与精简**：以真实经历为基础，对整份或单项简历按行业、年资、岗位优化结构、技术或业务深度、职责和成果表达。可以有力度地写出做过的事，不要求每一句都有第三方证明，不强制使用数字或缩成一页；不得编造学历、岗位、技能、主导身份、业绩与验收结果。
- **可见且可控**：完整 A4 改写前后对比、事实风险提醒、确认应用、撤销、版本隔离、投递前质量检查和 PDF 导出。
- **可靠数据保护**：支持完整母版及岗位版本的备份恢复；模型只在用户主动触发并了解数据范围时调用，不静默上传全量母版或扫描本地私人目录。

理想完整流程：

**选择/上传真实文件 → 结构化母版与人工确认 → 指定岗位/JD → 本地选材及可选 AI 全篇生成 → 完整对比与确认 → 独立岗位版本 → 润色/质量检查 → PDF。**

无 AI 或额度不足时，仍能选择母版素材、创建版本、编辑和导出。

非目标：重复建设内容库、默认扫描电脑文件夹、自动投递、伪造 ATS 官方评分、把第三方认证当成前置条件或规定所有行业必须使用一页校招模板。

最新开发基线：原母版选材生成与匿名 Chrome 回归通过；**P0-A 原件优先且结构化优先：DOCX/PDF 添加后不触发提取或 AI，主动提取并保存后停止读取对应原文件；已验证编辑后 AI 读取最新字段而非过期原文，以及中文文字型 PDF/扫描型 PDF 的处理差异**。P0-B 跨栏目选材与只读 A4 预览已接入，新增可选 AI 多栏目描述文字改写、事实校验、完整双 A4 审阅、逐项确认后保存新岗位版本；模拟模型端到端验收通过，**不代表已验证真实 AI 整份生成质量或完全防幻觉**。复杂分栏、浮动 Word 内容和低质量 PDF 需继续实测，不将一次匿名测试等同所有真实简历兼容。具体项目自动测试与构建次数以本次研发验证记录为准。现有修改未提交、未推送、未发布。

## 三、下一阶段目标与验收

**优先级调整（2026-11-09，用户确认）：完整母版备份与恢复安排在主要制作、生成、润色和投递体验完成后的最后阶段，不作为当前首项开发任务。** 延后该功能不代表可忽略用户数据安全；在备份功能完成前，不做破坏性存储迁移或数据清理，涉及现有用户数据的高风险更改必须先确保可恢复。

### P0-A｜Word 与 PDF 原稿导入、结构化和人工确认

目标：同一个母版导入入口支持 **Word（优先 DOCX）与 PDF** 两种简历原稿，复用现有附件、解析及导入审阅能力，不新建第二套母版。Word 解析段落和表格；带文字层 PDF 提取正文并恢复合理的阅读顺序；扫描型/图片式 PDF 需识别并提示，可在合适的本地 OCR 能力可用时识别，无法可靠提取时应提示用户重新提供可复制文字的文件或手动校对，不能凭空补全文字。形成教育、项目、工作/实习、技能、奖项等候选条目，支持用户先添加原文件、AI 需要时主动检索、需要编辑时一键提取可编辑副本，修改、增加、移除误识别项后保存，无强制逐项勾选。

验收：分别使用真实 DOCX、文字型 PDF、扫描/图片型 PDF 检查字段提取、表格/分栏顺序、跨页合并、中文字符、日期与项目归属；清楚标示不能提取的字段和识别不确定性。不得因“文件已上传”就宣称“完整母版已导入”；未经确认不覆盖已有母版，不自动读取用户磁盘路径，也不静默把私人原件发给云端模型。

**P0-A 本轮已完成范围：** 原件本地保存、去重、按需提取、初步字段分组、结构化编辑、同库原子入库与关联移除；对图片式 PDF 明确提示需 OCR/人工录入。**待补充：** 复杂 Word 文本框/表格、PDF 多栏多页的真实样本精度和可靠离线 OCR。结构化教育/技能/奖项参与岗位版生成已经在 P0-B 第一阶段完成。
### P0-B｜完整母版驱动的岗位简历生成
目标：升级「从母版生成岗位版」为跨教育、项目、经历、技能、奖项的岗位化选材，并提供可选 AI **整份撰写**、完整 A4 候选预览与逐项确认；保留无模型的本地选材生成路径。

验收：清楚解释推荐/未采用的来源及原因，不把 JD 关键词变为用户技能；原稿与候选稿可完整对比；仅用户批准后创建新版本；失败可撤销或不产生副作用，不影响其他岗位稿。

**已完成第一、二阶段：** 本地读取已保存的教育、技能、奖项和项目/工作结构化内容，不重新解析已提取的 Word/PDF；分组勾选、岗位术语排序、只读 A4 预览、原版本隔离及提交前变更复核。用户明确点击「用 AI 专业改写」并确认数据范围后，才向已配置模型发送不含结构化姓名、学校、联系方式和文件 Blob 的有限描述字段及 JD；服务端校验每条建议的原文引文、技术/指标/职责/阶段风险，用户在左右完整 A4 中选择改动后独立存储。无模型/失败时仍可本地生成。**待验收：** 真实模型专业水准、跨项目语义误用、信息遗漏、极长文档与最终 PDF 实体。**模型环境实际检查：** 当前公开模型列表为空，本地 Ollama 不可达；新增 [四岗位质量评测基线](ROLE_RESUME_QUALITY_EVALUATION.md)，离线 23 项合成场景全部符合预期，修复明确排除职责反向认领与协助升级成全面负责的漏判。真实模型费用与配置未授权，不将规则测试误称为质量评测完成。

### P0-C｜整份与单项润色充分利用内容库
目标：以**当前版本**为主、完整母版中的相关经历为参考；支持整份简历与单项项目/工作描述的专业润色、岗位定制和适度精简，不机械压缩。

验收：不同项目不能串用职责或成果；真实工作不会一律降格为“尝试/待验证”；新数字、角色、任职、技术与完成状态必须有依据；显示改动前后、解释与风险提示，用户确认后采用并支持撤销。至少覆盖实习、社招、跨领域岗位的正反用例，并另做真实模型盲评。

### P1｜投递验收与体验

对最终输出的 PDF 核对 A4、中文文字层、阅读/复制顺序、字体、分页；完善多窗口、窄屏、不同 DPI、离线/模型失败场景。保留岗位 JD 与审查结果的版本关联，不声称招聘平台官方 ATS 分数或录用概率。

### P2｜检索质量及工程优化

在真实母版规模和岗位样本足够后测量关键词检索的漏选/误选，再比较本地 Embedding、混合检索及缓存方案。优先复用已有工程与增量产物；不因概念追新引入多余服务、重复数据库和大体积缓存。

### P3（最后阶段）｜完整母版备份与恢复

目标：在不破坏原本地存储方案的前提下，支持结构化简历版本、contentEntries、附件原件、识别候选和来源记录的一体化导出、恢复与迁移；默认不上传云端。此项**明确安排在本轮产品核心功能完成后实施**，不提前宣称已具备完整备份能力。

验收：隔离浏览器中建立附件、母版和岗位版本，备份后在新环境恢复；文件哈希、ID、条目数量和来源关系一致；面对重复、冲突、损坏或容量不足，不破坏现有数据。普通 localStorage JSON 不能称作“母版全量备份”。

**延期风险提示：** 当前母版 IndexedDB 尚无全量备份，清除站点数据、浏览器故障或迁移设备可能导致资料丢失。在 P3 完成前应保留原始 Word/PDF/证书文件，继续使用已有的简历 JSON 导出保存已支持的版本资料，并避免清理浏览器站点数据；这仅是临时风险控制，不等同完整母版备份。

## 四、研发与数据边界

1. **继续维护既有母版**：IndexedDB 的 attachments 与 contentEntries 属同一个用户母版；扩展数据结构要有兼容、迁移验证与异常恢复，不能直接清除旧数据。
2. **真实但不过度苛刻**：本人明确陈述、面试能解释的日常职责可以正常润色；缺少外部证明不等于虚假。明显矛盾、凭空新增身份/能力/指标、将未完成写成已全面验收，则需要拦截或提醒。
3. **用户确认和版本隔离**：所有重要导入、生成、改写先预览再采用；不覆盖现有原稿/岗位版本；不可逆的更改先确认。
4. **最小必要发送**：调用模型须主动触发，区分本地与云端，只发当次必要内容；原始证书、成绩、联系方式等敏感信息遵守现有隐私规则。
5. **工程验收**：复用 node_modules、dist 和原有测试目录；做类型、测试、构建、浏览器/导出检查；不擅自删除项目历史缓存、提交 Git 或发布。
6. **文档职责**：本文件负责目标、阶段优先级、完成定义；README 负责概览及运行；RGS 负责真实性和生成质量标准；MASTER_CONTENT_WORKFLOW 负责已实现的母版数据与交互契约。里程碑完成后同步更新本文件和相关规范。

## 五、下次接手断点

先检查真实 Git 工作树、原 IndexedDB 数据及当前测试，再读本文件、README、RGS、母版工作流。**不要把现有本地选材生成岗位版误报为 AI 已完成整份专业写作。**

建议按 **P0-A Word/PDF 母版导入 → P0-B 完整岗位简历生成 → P0-C 整份/单项润色 → P1 投递验收 → P2 检索与工程优化 → P3 母版全量备份恢复（最后完成）** 的顺序继续。每阶段记录变更文件、实际测试证据与剩余风险；不得因备份任务延期而擅自进行不可恢复的迁移、删除或覆盖，未经授权不触碰用户 C 盘原始 Word/PDF 文件。
